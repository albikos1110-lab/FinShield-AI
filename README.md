# FinShield AI

**AI-Powered Financial Fraud Detection and Investigation Platform**

[![Open In Colab](https://colab.research.google.com/assets/colab-badge.svg)](https://colab.research.google.com/github/albikos1110/FinShield-AI/blob/main/FinShield_AI.ipynb)

## About the Project

FinShield AI is an AI-powered platform designed to detect suspicious financial transactions, investigate potentially risky accounts and transaction networks, and improve financial fraud awareness.

## Features

### 1. Fraud Detection

- Detects potentially suspicious financial transactions using Machine Learning.

- Uses a Random Forest classification model.

- Applies SHAP to explain the factors influencing predictions.

### 2. Fraud Investigation

- Analyzes individual accounts and transaction activity.

- Examines transaction networks using NetworkX.

- Uses Groq AI to generate reports about overall network patterns.

### 3. Fraud Simulator

- Generates interactive financial fraud scenarios using Groq AI.

- Helps users recognize warning signs of financial scams.

- Provides explanations of correct answers.

## Technologies Used

- Python

- Pandas

- NumPy

- Scikit-learn

- Random Forest

- SHAP

- NetworkX

- Gradio

- Groq AI

## Dataset

PaySim synthetic financial transaction dataset.

## Disclaimer

FinShield AI is a prototype and is not connected to real banking systems. It uses synthetic demonstration data. Risk indicators are not proof of fraud.
